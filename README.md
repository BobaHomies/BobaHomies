🧋 Boba Homies Website
A cozy, modern landing page for Boba Homies, showcasing handcrafted milk teas, featured drinks, and store information. This project is built using simple HTML, CSS, and a bit of JavaScript to create a clean and responsive user experience.

✨ Features
📌 Fixed navigation bar for easy browsing
🌄 Hero section with overlay and call-to-action
📖 About section telling the brand story
🧋 Featured drinks with images and descriptions
📋 Clickable menu image with popup (lightbox effect)
📱 Responsive design for mobile and desktop
📍 Contact section with store info and social links

🛠️ Technologies Used
HTML5 – Structure of the website
CSS3 – Styling, layout, and responsiveness
JavaScript – Menu popup interaction
Google Fonts – Typography (Poppins & Playfair Display)

🚀 Getting Started
Clone the repository:
git clone https://github.com/your-username/boba-homies.git
Open the project folder:
cd boba-homies
Open index.html in your browser.

💡 How It Works
The menu image is clickable and opens a fullscreen popup using JavaScript.
The layout uses CSS Grid and Flexbox for responsiveness.
Sections are organized for smooth scrolling navigation.
